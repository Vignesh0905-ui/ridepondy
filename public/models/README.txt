# RidePondy 3D Model Assets Directory

This directory is intended for GLTF / GLB 3D models of motorcycles.

To supply a custom high-poly or realistic motorcycle 3D asset:
1. Place your licensed or custom `.glb` model here named: `motorcycle.glb` (Path: `/models/motorcycle.glb`).
2. The RidePondy IntroLoader automatically attempts to load `/models/motorcycle.glb` using Three.js GLTFLoader.
3. If no GLB file is placed here, the IntroLoader immediately utilizes the built-in, realistic Three.js PBR sportbike model with metallic bodywork, twin-spar chassis, disc brakes, rotating alloy wheels, and inverted gold forks.
